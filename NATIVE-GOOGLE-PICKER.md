# Kivora native Google account picker

This project uses `@capacitor-firebase/authentication` for Android-native Google sign-in. The Android branch in `src/firebase.js` deliberately does not use `signInWithPopup` or `signInWithRedirect`; if native sign-in fails, it shows an error rather than sending the user to Chrome.

## Required Firebase setup

1. In Firebase Console → Project settings → Your apps, register an **Android** app with package ID `com.kivora.app`.
2. Download that Android app's `google-services.json` and save the entire JSON file as the GitHub Actions repository secret `GOOGLE_SERVICES_JSON`.
3. In Firebase Authentication → Sign-in method, enable Google.
4. Add the SHA-1 and SHA-256 fingerprints for the certificate that signs the APK you install (debug and release signing certificates can differ) under the Android app in Firebase project settings. Download `google-services.json` again after changing Firebase app/OAuth configuration and update the secret.
5. Ensure the JSON contains a `client_type: 3` Web OAuth client entry as generated by Firebase. Do not manually replace client IDs with the Android client ID.
6. Run the `Build Kivora APK` GitHub Actions workflow and install the newly generated APK artifact. A Vercel redeploy alone does not update the native APK's bundled JavaScript.

## Important distinction

Native account-picker code only runs in a Capacitor Android APK where `Capacitor.isNativePlatform()` is true. A Trusted Web Activity (TWA) or browser-installed PWA cannot invoke this Capacitor plugin; it needs a separately implemented Android bridge. If sign-in still redirects to `kivora-ecru.vercel.app` after installing a freshly built Capacitor APK, check that the APK came from this repository's `Build Kivora APK` workflow and that the package ID is `com.kivora.app`.
